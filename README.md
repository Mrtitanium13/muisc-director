# Music Director

Suno AI prompt engineering for DJ-ready track generation. Ensures every Suno output includes a **DJ Mix-In intro** and **DJ Mix-Out outro** — the bookend sections Suno routinely skips when instructed negatively.

## Architecture

```
prompts/sections/          Raw section text (1A–1F)
lib/                         Dart prompt loaders + buildDjMixUserBlock
python/muisc_director/       Python mirror (parity with Dart)
prompts/generated/           Merged system prompts (regenerated by scripts)
```

### Section 1F (DJ Mix Bookends)

Section 1F uses a **positive content-first** approach: it tells Suno exactly what to generate (filtered 8–16 bar mix-in, 16–32 bar mix-out at steady BPM) rather than listing what to avoid.

## Usage

### Regenerate merged system prompts

```bash
# Dart
dart run bin/regenerate_system_prompts.dart

# Python
python python/scripts/regenerate_system_prompts.py
```

### Build a DJ mix user block

```dart
import 'package:muisc_director/build_dj_mix_user_block.dart';

final block = buildDjMixUserBlock(DjMixRequest(
  trackTitle: 'Midnight Pulse',
  genre: 'deep house',
  bpm: 124,
  djTag: 'DJ Titanium on the decks',
));
```

```python
from muisc_director.build_dj_mix_user_block import DjMixRequest, build_dj_mix_user_block

block = build_dj_mix_user_block(DjMixRequest(
    track_title="Midnight Pulse",
    genre="deep house",
    bpm=124,
    dj_tag="DJ Titanium on the decks",
))
```
