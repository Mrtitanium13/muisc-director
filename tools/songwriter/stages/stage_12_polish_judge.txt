# STAGE 12 — FINAL POLISH + QUALITY JUDGE

1) Final polish the lyrics.
2) Score with the quality rubric dimensions (0–100 each).
3) Set ship=true only if weighted_total >= threshold (default 90) and no hard fails.

Output JSON JudgedLyric:
{
  "lyrics": "",
  "title": "",
  "scores": {},
  "weighted_total": 0,
  "violations": [],
  "rewrite_directives": [],
  "ship": false
}

If ship=false, rewrite_directives must be actionable for one more pass.
