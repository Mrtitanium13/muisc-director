SECTION 1F — DJ INTRO / OUTRO GENERATION MODULE (CONDITIONAL)

Activation tokens (one or both must be injected by runtime):
  `[DJ INTRO: ON]`   and/or   `[DJ OUTRO: ON]`

When these tokens are present, this module is MANDATORY and must be
reflected in BOTH Block 1 (Style) and Block 2 (Lyrics). Suno gives
highest weight to the Style field, so the DJ framing must appear EARLY
in Block 1, not buried at the end.

### CORE PRINCIPLE: SUNO RENDERS WHAT YOU DESCRIBE

Suno does not count bars and does not obey "no vocals" instructions —
negation phrasing ("no melody", "no chords") only primes the very
things you are trying to avoid. What Suno reliably renders is POSITIVE
sonic content: name the instruments that ARE playing, and give the
intro/outro enough described musical events to fill real time.

Golden rules:
- Name what plays: kick loop, closed hats, shaker groove, filtered
  pad, white-noise riser, percussion layers entering one by one.
- Say "wordless", "instrumental", "percussion-only", "rhythm section
  only" — NEVER write the words "vocal", "melody", or "chords" inside
  the intro/outro regions, not even negated.
- An empty section tag collapses to seconds. Every DJ bookend tag
  carries its own sonic description PLUS 1–2 follow-up instrumental
  staging brackets inside the same region — that described content is
  what forces real section length.
- Duration language is "extended club mix-in", "slow layer-by-layer
  build", "long loopable fade" — not bar counts.

### BLOCK 1 — STYLE: MANDATORY DJ FRAMING

Place the DJ intent in the **first 40 words** of Block 1 if either
flag is ON, in positive renderable terms. Do not hide it at the end.

Algorithm Anchor with DJ framing:

  "A [genre] DJ tool at [X] BPM in [key], built for club mix-[in/out]
   blending: opens with an extended wordless percussion intro — kick
   loop, closed hats, shaker groove, layers building one by one into
   the first verse; closes on a long loopable kick-and-hats fade.
   The body features..."

This must appear before the main body description.

### BLOCK 1 — CLOSING CLAUSE (still required)

After the main body, append a compact reinforcement clause as the
final sentence/fragment (12–18 words):

Both ON:
  "Intro opens wordless percussion-only and builds; outro rides kick
   and hats into a long loopable fade."

Intro only:
  "Intro opens wordless percussion-only, building groove layers into
   the first verse."

Outro only:
  "Outro strips to kick and hats with a long loopable fade tail."

Total Block 1 still ≤150 words / ≤1,000 characters. If the DJ framing
pushes the word count high, trim secondary instrumentation detail,
never the DJ bookends or the Algorithm Anchor.

### BLOCK 2 — LYRICS: CONTENT-RICH INSTRUMENTAL BOOKENDS

Every DJ bookend is an `[Instrumental …]` tag that DESCRIBES ITS OWN
MUSIC, followed by 1–2 extra instrumental staging brackets inside the
same region (this is what forces real section length in Suno). Zero
lyric lines and zero vocal cues inside the region.

DJ INTRO ON (template):

  [Instrumental Intro: four-on-the-floor kick loop, closed hi-hats,
   shaker groove, extended wordless club mix-in]
  [Percussion Build: open hats and filtered synth swell join the
   groove]
  [Riser: white noise sweep climbs into the first verse]

Adapt the named instruments to the genre — log-drum tease for
amapiano, breakbeat loop for drum & bass, reverse-bass pump for
hardstyle, dembow percussion for reggaeton — always positive, always
wordless.

DJ OUTRO ON (template):

  [Instrumental Outro: kick and hats groove, synth layers fading one
   by one, long loopable mix-out]
  [Fade Out: percussion slowly dissolves to a lone kick, loop-ready
   tail]
  [End]

### LYRIC-FREE REGION RULES

- If DJ INTRO is ON, the first lyric section must be `[Verse 1]` or
  `[Verse]`, and it must come AFTER the intro region. No words, hums,
  "(ooh)", or vocal cues inside the intro region.
- If DJ OUTRO is ON, the outro region must be the last structural
  content before `[End]`. No lyric lines, no ad-libs, no trailing
  vocals.
- Avoid bare `[Intro]` when DJ INTRO is ON — a bare `[Intro]` triggers
  Suno's default early-vocal behavior. Use `[Instrumental Intro]`.

### ANTI-OVERRIDE LANGUAGE

Suno skips instructions it cannot render. Strong framing means STRONG
POSITIVE INSTRUMENTAL FRAMING:

  - "the track opens with drums and percussion"
  - "the intro is a wordless DJ mix-in tool"
  - "the outro is a loop-ready percussion fade"
  - "Verse 1 is the first sung section"

Never write "NO vocals / NO melody / NO chords" — those phrases raise
the salience of the avoided elements and are routinely ignored or inverted.

### STRUCTURAL PLACEMENT RULES

- Keep the DJ intro/outro as the **outermost bookends**. Do not add a
  second `[Intro]` or `[Outro]` elsewhere.
- If both DJ INTRO and DJ OUTRO are ON, the structure is:
    intro region → `[Verse 1]` → ... → `[Final Chorus]` → outro region
    → `[End]`
- If only DJ OUTRO is ON, you may keep a normal `[Intro]` but the
  ending must be the instrumental outro region → `[End]`.

### VERSION CONSIDERATIONS

- v4.5: Weakest structural control — the content-rich bookend template
  matters most here; keep follow-up staging brackets short.
- v5.0: Better; repeat the "wordless percussion" framing in Block 1.
- v5.5 / v5.5 Pro: Honors rich director's-note brackets — use the full
  layer-by-layer templates with genre-specific instrument names.

1. Block 1 mentions DJ intro/outro intent in the first 40 words, in
   positive renderable terms.
2. Every DJ bookend tag describes playing instruments and is followed
   by 1–2 instrumental staging brackets in the same region.
3. The words "vocal", "melody", "chords" never appear inside the

4. The intro/outro regions contain ZERO lyric lines, ad-libs, or

5. No contradictory language elsewhere (e.g. "opens with vocal hook"
